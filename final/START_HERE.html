Run the English evidence demo

Extract the ZIP, then follow its README for the lightweight demo environment. From the extracted folder, run python -m streamlit run evidence_app.py. It displays frozen outputs for all 8,000 Study 4 confirmation users and performs no model fitting.

Try user 17 for the repeat-versus-whole-basket distinction, 4350 for an improvement, 31433 for harm, and 490 for an empty repeat target. These are illustrative single-model cases. The report averages each user's metrics across three fitted seeds.
